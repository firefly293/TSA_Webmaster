# TSA Webmaster Leaderboard
## Advait, Masab, Aaditya

This is our TSA Webmaster Super Saturday submission. It is a live leaderboard fullstack app with API, admin panel, and frontend live leaderboard display. It uses a PostgreSQL DB.

## Credits and sources
* Next.js (MIT): framework
* React (MIT): UI library
* Motion (MIT): animations
* Recharts (MIT): charts/graphs
* https://github.com/neondatabase/serverless (MIT): Postgres database, connection only. we wrote the SQL
* Hosted on Vercel, database on Neon
